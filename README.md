# shiftlane

Shift filesystem lane paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/shiftlane/

## Install / run

```bash
git clone https://github.com/theworker02/shiftlane.git
cd shiftlane
node src/cli.js
node --test
```
